# Demo / Maps

| Map | Purpose |
|---|---|
| `Stratagem_Gym.umap` | The main test arena — `BP_DummyTarget` instances placed for playtesting offensive Stratagems, open space for Sentry placement and Air Strike testing |
| `MainMenu_Demo.umap` | Simple menu — Play / Quit, using `WB_MainMenu_Demo` (see [`Widgets/`](../Widgets/README.md)) |
| `EditorOpenMap.umap` | The map that opens by default when the project is opened in-editor |

> **Set `Stratagem_Gym` as the map to open directly if you just want to test the system** — `MainMenu_Demo` exists only so the project has a complete, presentable demo flow (menu → gameplay), not because the system needs one.
